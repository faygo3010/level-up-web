# Level Up — Landing Page

The marketing landing page for **Level Up**, an AI life progress tracker. A single static `index.html` (HTML + CSS + vanilla JS — animated hex background, live progress bars, tabbed app preview, FAQ accordion). No build step, no dependencies.

## Files
- `index.html` — the entire site
- `render.yaml` — Render static-site config
- `.gitignore`

## Deploy on Render
1. Push this repo to GitHub.
2. On Render: **New → Static Site**, connect the repo.
3. Build command: leave empty. Publish directory: `.`
4. Deploy. (Or use `render.yaml` via Render Blueprints.)
